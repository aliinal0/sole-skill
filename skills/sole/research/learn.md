# Learn - explain so it sticks

1. **Find the level.** One quick question or infer from how the user asks: beginner, practitioner, expert. Store it in CONTEXT.md preferences if the topic continues.
2. **Big picture first** in 2-3 sentences: what it is, what problem it solves.
3. **One concrete example** before any abstraction. Use the user's own domain when known.
4. **Build up** in small steps; each step uses only what was already explained.
5. **Name the common confusion** ("people mix X up with Y because...").
6. **Check understanding** with one short question or a tiny exercise, only if the user wants to learn (not when they just need the answer).
7. **Point to the next step**: what to learn next, one good source.

Keep it short. Use a diagram or table only when it explains better than words. Current facts (versions, prices, laws) -> verify with a search first.
